# ☁️ Projeto Aeris

O **Projeto Aeris** é uma aplicação web de previsão do tempo que permite consultar informações climáticas de qualquer cidade de forma rápida e intuitiva.

Além de exibir dados como temperatura e umidade, o projeto conta com uma funcionalidade inteligente de sugestão de roupas com base nas condições climáticas. 👕

---

## 🌐 Funcionalidades

- 🔍 Busca de clima por cidade  
- 🌡️ Exibição de temperatura em tempo real  
- 💧 Informações de umidade do ar  
- 👕 Sugestão de roupas baseada no clima  
- 📱 Interface responsiva e moderna  

---

## 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript  
- APIs externas de clima e IA

---

## 🚀 Como usar

1. Digite o nome de uma cidade no campo de busca  
2. Visualize as informações climáticas  
3. Clique no botão de sugestão de roupas  
4. Veja recomendações baseadas no clima atual
